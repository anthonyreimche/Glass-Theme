# Glass

Safelight theme — neutral frosted glass. A light grey tint over the window's acrylic material, so the desktop shows through, with white text and grey glass controls. Menus, dropdowns, dialogs and floating panels are frosted glass, tuned against a translucent Windows Start menu: a soft blur under a light grey tint.

Needs Safelight 3.2.1 or later. The glass shows on Windows 11 22H2 and later and on macOS. Elsewhere, on the software graphics backend, or with Reduce transparency on, the theme stays opaque and looks like a plain grey theme. The Develop canvas surround is always opaque, so the photo is judged against a solid background.

Install from the Extensions panel: `owner/safelight-theme-glass`. Apply via View ▸ Theme. No build step; `index.js` is the bundle.
